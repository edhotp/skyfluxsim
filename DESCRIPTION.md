# SkyFlux RF Simulator Description

SkyFlux RF Simulator adalah aplikasi web statis untuk belajar dasar-dasar RF video link FPV 5.8 GHz secara interaktif. Aplikasi ini memvisualisasikan pengaruh gain antena, efisiensi, SWR, mismatch polarisasi, kondisi lingkungan, multipath, dan interferensi terhadap kualitas link video.

Target pengguna:
- Pilot FPV pemula yang ingin memahami konsep RF secara praktis
- Komunitas FPV untuk edukasi dan diskusi setup antena
- Pengguna yang ingin simulasi cepat tanpa instalasi

Karakteristik utama:
- Berjalan langsung di browser (tanpa backend)
- Dua bahasa (Indonesia/English) pada aplikasi utama
- Dokumentasi terpisah yang mudah dipahami orang awam
- Visualisasi metrik link budget, RSSI, SINR, dan status link secara real-time

Catatan:
- Ini adalah alat edukasi/simulasi, bukan jaminan performa dunia nyata.
